# Heyang Chen GitHub Pages Homepage

This is a static personal homepage for GitHub Pages.

## Edit

- `index.html`: page content, links, email, publications, and project entries.
- `assets/styles.css`: visual styling and responsive layout.
- `assets/main.js`: mobile navigation and the animated lattice visual.

## Publish

Create a GitHub repository named `aioyouko.github.io`, then push this folder to the `main` branch.
This local repository is already configured with:

- Git author email: `aioyouko@gmail.com`
- Remote: `git@github.com:aioyouko/aioyouko.github.io.git`

```bash
cd /Users/chenheyang/Documents/Github/aioyouko.github.io
git add .
git commit -m "Create homepage"
git push -u origin main
```
