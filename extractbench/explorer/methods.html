Curves and statistics

The Explorer uses the homepage’s neutral surfaces, teal accents, and typography. SVG plots, Gold-range zoom, model comparison, repeated-question overlays, and numeric Mean / sample-SD tables retain their original calculations and interactions. Display units follow the original explorer. Temperature and value conversions use the archived benchmark scorer. Parse failures expose no repaired or fabricated curves; usable schema-anomalous records remain visible.

The current-question metrics use all Gold points for that sample and property. The historic explorer's ≤5%, 5–10%, 10–20%, >20%, and missing bins are retained, with ≤15% additionally exported in the metrics CSV. D1 retains its zero-reference convention and D2 retains its own convention. These local, point-weighted curve diagnostics are different from the benchmark's performance-macro Y5/Y10/Y15 summaries, which are available in the unchanged Origin summary export.

Each nonempty question contributes its returned curve to the repeated-question overlays. Mean, median, IQR, and sample SD describe the available aligned values; missing values are not filled with zero. Slot coverage keeps the planned relevant-question denominator. Normalized robust spread is median 1.4826 × MAD / |median| after removing each curve's median scale relative to Gold. Shape bias is the normalized center's absolute deviation from Gold. These describe consistency across presentations, not repeated-call sampling variance or a controlled causal comparison.

Each question/property's reconstructed Gold count, prediction count, covered count, missing count, and ≤5/10/15% counts are checked against the existing Origin source scores before the dataset is emitted. Scientific scores, raw responses, the original explorer, and the seven existing workbooks are not rewritten.

Files and reproducibility

Curve datasets load on demand. The dataset ZIP download contains prediction curves, Gold reference values, question metrics, and sample stability as four CSV files. Unzip before opening in a spreadsheet application. Missing values remain distinct from zero.

The public export contains scored curve data and configuration-level audits. Original model responses and operational source paths remain in the research archive. File checksums and the exact source-bundle checksum identify this release.
